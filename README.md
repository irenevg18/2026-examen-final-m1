# 2026-examen-final-m1
Examen final del módulo 2026

> ### Instrucciones 
> 1. Crea un repositorio (público) propio para trabajar.
> 2. Copia y pega este *reeadme* y el archivo *challenges.js* en tu nuevo repositorio.
> 3. Recuerda hacer ```git add.```, ```git commit -m "tu mensaje"``` y ```git push``` a menudo.
> 4. Una vez hayas terminado, haz push en tu repositorio y entrega el enlace. (Para entregar el enlace: mandáselo a la profesora por teams y escríbelo en boli azul en la hoja del examen).

Este examen consta de 2 partes: 
- Una para evaluar tus conocimientos de HTML y CSS.
- Otra para evaluar tus conócimientos de JS.

## PARTE 1
Vas a crear una landing page sobre un tema que te guste (plantas, café, fotografía, música, viajes, etc.).
Tiene que tener al menos:
- Una Navbar
- Un header
- Un footer

**⚠️ El código tiene que estar escrito por ti, no por la IA.**
**En caso de duda, la profesora te pedirá que expliques tu código.**

## PARTE 2
Resuelve los ejercicios del archivo *Challenges.js*. 
**⚠️ El código tiene que estar escrito por ti, no por la IA.**
**En caso de duda, la profesora te pedirá que expliques tu código.**
